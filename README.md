# 🧠 Health Consultancy with AI

This is a Final Year Project that provides AI-based health consultancy. The system allows users to input their symptoms and receive a prediction of possible diseases along with health recommendations.

---

## 🚀 Features

- 🌐 **React Frontend**: Interactive UI for symptom input and result display
- 🐍 **Python Backend**: AI model for disease prediction and recommendations
- 📊 **Symptom Analyzer**: Accepts user symptoms and predicts likely conditions
- 💡 **Recommendations**: Provides general advice based on predicted illness
- 📡 **API Communication**: Seamless data exchange between frontend and backend

---


## ⚙️ Tech Stack

| Layer     | Technology         |
|-----------|--------------------|
| Frontend  | React.js           |
| Backend   | Python (Flask) |
| ML Model  | Scikit-learn  |
| Styling   | Tailwind |
| Communication | REST API (Axios) |
